# Independent review and corrections

The same experiment worker and independent reviewer were reused. They were
given bounded contracts, separate ownership, no recursive delegation and no
production or Git-index authority. Parent retained experimental decisions,
scoring, integration and conclusions.

Before encoding:

- The worker proposed another variance-boost experiment. Parent rejected it
  for this round: it would revisit allocation before testing the distinct
  search/decision-policy uncertainty. Preset0 was selected once, with preset4
  and all other external settings fixed.
- The reviewer initially cited NVENC A-base9.648396Mbps as the SVT baseline.
  Parent required the actual B command/IVF/MKV/metric chain. Correct B scored
  rate is9.6763312Mbps; its IVF payload is9.6767152Mbps. Both are documented.
- The worker's first Y4M parser expected colon-separated width/height fields.
  The actual header usesW1920/H1080. Correct parsing was checked against the
  new fixture before encoding.
- Parent required effective-preset log checks, complete reconstruction shape,
  explicit packet cadence, scored-MKV rate accounting, executed-script copies
  and binding to the full336 historical input. Requested settings alone do
  not prove an intervention occurred.
- Reviewer flagged that an early `encoded` status could survive failed
  post-validation. Final runner now uses `validating` until all checks finish.
  The already running arm retains its exact earlier script; the scorer's
  independent complete-receipt/hash/rate checks prevent false admission.
- Reviewer required paired whole-window controls with the frozen outside mask,
  MSE p95 and signed quiet-HF tails. Parent implemented these and explicitly
  labeled the mask's historical scope.
- Reviewer recommended binding live validity and full-input receipts to their
  encode-time/historical hashes. Parent added both checks.
- The summary script initially trusted same-tag upstream files without all
  cross-links. Reviewer required command/assessment/metric/texture/live-output
  binding and raw-control provenance. Parent added those assertions, corrected
  “complete controls” to “control summaries,” linked full evidence and moved
  output-directory creation after validation.

The pre-score review found the corrected admission path consistent with the
contract. When the run landed below99%, parent separated practical eligibility
from matched-comparison eligibility in an explicit mode. Independent review
approved that distinction before quality results, with both rate ratios and
eligibility flags preserved. No texture/control/playback gate changed.

Outcome review accepted the completed preset0 arm as a valid failed under-cap
screen. It independently verified all336 decoder samples, complete source/hash/
settings identity, source/B rates and nonmatched labeling. The amplitude failure
is broad: only7/240 shirt and6/240 background frames meet the HF tolerance.
Those fixed-coordinate full-window counts include changing scene content and
are corroborating traces, not a new confirmatory gate.

The reviewer found quiet-HF mean error and quiet-MSE p95 regressions that pooled
quality improvements could hide. Parent retained them and inspected native
shirt/background stills. Neither party claimed playback.

The reviewer recommended testing the independent libaom policy next: the large
amplitude misses make a repeat45.7-minute preset calibration less informative
for feasibility. Parent accepted that recommendation while explicitly leaving
the matched-rate preset effect unresolved. It is not a claim that extra bits
cannot alter a result or that AV1 has reached a limit.

Round2 preflight found discrepancies between the worker's claimed checks and
its first runner implementation: requested color was not validated, input was
not hashed after encoding, pass1 statistics had no preserved snapshot, and
linked-library identity was inferred from an installed filename. Parent explained
that requested controls and file existence do not prove the measured path, gave
focused revisions and then integrated the remaining receipt corrections.

Independent review additionally required a pinned/hashed system ffprobe,
snapshot-path rather than mutable-source-path provenance, and zero packet origins
because downstream scoring also uses time-based extraction. These were corrected
before the measured libaom arm. Failed validation cannot leave an admitted status.
The runner retains per-pass commands/status/log hashes, exact pass1 statistics,
full IVF/MKV packet arrays, input before/after hashes and separate encode time.

The libaom scoring review accepted three-decoder equality and the unchanged
source/control math. Parent added explicit case/tag and decoder-set bindings,
verified probe and pass-log hashes, and named the raw file `dav1d-decoded.yuv`.
It is decoder output, not an encoder application reconstruction. The summarizer
uses a stack-specific decoder flag and exposes this distinction. Neither reviewer
nor parent inferred all temporal preprocessing absent from requested ARNR0.

The companion fixed-input grain probe received independent outcome review.
Reviewer rechecked all provenance hashes, all3 qualifying pairs and8 common-code
rows, max-overlap/max-min-count selection, NPZ constant neighborhoods and mask
indexing, native all-plane base identity,32 unique fixed seeds, exact equality of
conditional output/isolated-grain HF, and zero selected endpoint occupancy.
No material validity defect was found. Parent retained the reviewer's strongest
limitation: white16 overshoots both source intervals, so zero joint hits alone
does not reject other scales or AR shapes. Similar ensemble magnitudes under the
same decoded input support a local conflict; individual responses differ.
The report states raw code192 means8-bit48, uses frozen texture class without
claiming stochasticity, and makes no temporal or signaling-cost assertion.

Round2 outcome review independently verified actual/source/B packet ratios,
pass-statistics/input/provenance identities, all3decoder equality and scored
sample selection. It confirmed both amplitude/ACF failures and retained face,
VMAF/NEG, lower-tail and tilewise regressions despite broad mean improvements.
The next recommended discriminator is libaom's PSNR versus SSIM tune policy with
all other declared controls fixed and actual rates matched. Parent accepted this
as a whole-encoder policy contrast, without asserting unchanged internal search,
allocation or quantizer decisions. No playback was claimed.

Round3 pre-result comparison review required live/cross-arm pass1 snapshot
identity, exactly240 texture rows with identical ROI definitions, explicit
requested TBRs and a rate-calibrated scope label. Parent implemented all four.
The preserved SSIM summary predates the new tune-policy field, so it is bound
exactly to the committed `aom-result.json`; the new PSNR summary must cross-bind
its tune field to its command receipt. This preserves verified old evidence
without rerunning unchanged metrics or rewriting its receipt.


Round3 outcome review independently bound all source, command, pass1-statistics,
output and score hashes. Actual PSNR rate is 99.6131% of source and 100.1531% of
SSIM; keyframe positions are identical. All 336 three-decoder/all-plane checks
and 240 scored-frame bindings pass. Both frozen midpoint amplitude/ACF screens
fail. Only 3 shirt and 2 background frames meet both gates across the full
fixed-coordinate traces; these counts are descriptive, not new acceptance rules.

The reviewer retained regressions hidden by pooled gains: 7,020 of 12,870 tiles
worsen in MSE and 6,893 in HF error; quiet/flat-texture controls worsen, as do
mean SSIMULACRA2/SSIM and CAMBI mean/max. It accepted face/edge improvements
without calling the arm uniformly better. No playback inference was made.
Parent agrees with the scoped rejection and the next source-boundary trace.
Preserved independent artifacts: `reviewer/round3-review.md` and `.json` under
the experiment root. These were formed before receiving the parent's conclusion.

The source-audit correction distinguishes a reachable filter path from material
sample changes. At ARNR strength zero, noncentral weights can truncate to zero;
`cpi->source` being allowed to point to a filtered buffer proves neither loss
nor equality. The next trace compares all visible planes and requires exact
private pristine-versus-instrumented output before causal interpretation.
