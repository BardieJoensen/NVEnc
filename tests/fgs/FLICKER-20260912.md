# Intermittent synthesis recovery: September 12 investigation

The reported Amphibia flashes are reproducible in the old ripple repair
(`e778a88b`) and the deployed `497caa64` encoder. Rejected synthesis fits and
insufficient usable flat blocks preserve the input picture. The next usable fit
previously enabled synthesized grain immediately. Alternating eligibility can
therefore put a strong overlay on just one or two frames.

The isolated branch `fix/fgs-rejection-flicker-20260912` starts at deployed
`497caa64`, without the unrelated pending fidelity optimizations. Diagnostic
commit `eba689cf` exposes rejection in debug decisions. Fix `e2c3a99d` requires
24 consecutive fresh usable fits with a settled model window after any
source-preserving gap. Its recovery state survives ordinary fit-history
resets. Explicit filter initialization, discontinuity reset and close clear it.
Existing rejection, syntax, chroma and ripple protections remain in force.

Preserving source means bypassing grain removal before lossy AV1 encoding;
it does not mean bit-exact output. No unsafe model is reused to bridge a gap.

## Limits and scoping

Later checks across all nine complete installed replacements found another
one-frame restart in Lost Tapes S1E5 at 01:30.257. The original bird patch has
SD 0; deployed `e2c3a99d` jumps from about 0.05 to 3.38 for one frame. This is a
strong remaining counterexample to treating the 24-fit hold as a complete fix.
It is pinned as `losttapes_recovery_negative`, with the original source retained.
The new `--case losttapes` regression tests all eight aligned frames and retains
the same 0.3 patch-SD and 4.0 source-RMS limits.

Candidate `a3657c73` (build compatibility correction `3778447e`) introduces
synthesis across 16 fresh accepted frames after the 24-fit hold. Matching source
residual is kept in all planes during that interval, accounting for any existing
luma retention. This avoids a denoised dip from merely reducing the grain curve.
The temporal cache remains unscaled, unsafe models are still rejected, and no
lookahead frame buffering is added. CPU state/variance tests, full GPU qualification and exact-container regressions
pass. Core `3778447e` is now deployed; `ramp-qualification.json` and
`ramp-rollout-record.json` retain the exact evidence and runtime identities. The 10-bit excerpt now
passes the unchanged source-patch limit (SD 0.24 versus old 3.17). An additional
8-bit-output trial does not pass that flat-source check: its fitting decisions
permit a longer synthesis run and the patch reaches SD 1.18. Its first ramp
frame is clean, but the remaining spatial model mismatch is unqualified. The
production flow uses 10-bit output; this result must not be presented as an
8-bit source-fidelity pass. See `ramp-8bit-limit.json`.


This causal recovery rule does not guarantee a minimum future synthesis run:
after 24 good fits a new unsafe frame must still fall back immediately. The
complete E10 has no one/two-frame on runs, but retains 7/8/9-frame runs. Four
reviewed residual bursts in E10 and S3E30 have luma grain RMS about 0.47–0.66
8-bit levels, versus 5.23 at the reported E10 flash. They are documented weak
transitions, not certified invisible on every display.

`scope-progress.json` and `header-scope/` record a read-only header audit of
1,464 installed repair receipts captured on September 12. All 88 Amphibia files
were scanned; 75 contain short-on header candidates. That does **not** mean 75
visibly damaged episodes. The scan neither certifies visible quality nor covers
the whole library. Source-referenced decoded witnesses, repetition and strength
must guide remediation; no download or replacement follows from a header flag.

Reproduction commands, immutable build paths and identities, source identities,
decoded CSVs, source metrics, baseline review and gate outcomes are in the local
evidence root. The broader auto-retention campaign remains manual-start only
and deferred until the running ripple repair finishes.
