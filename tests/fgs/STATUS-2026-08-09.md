# Current FGS architecture and next gate — 2026-08-09

This is the current entry point for the FGS research record. It does not erase
the chronological findings; it separates results that still change a decision
from results that were corrected or retracted later. Read the cited document
before relying on a number.

## Branch and deployment boundary

| line | purpose | output-changing FGS state |
| --- | --- | --- |
| `master` | conservative production line, merged with upstream NVEnc 9.31 | bilateral separator, residual-fitted model; no PSD, `modelsrc`, motion prototype or response closure |
| `fgs/test-automation` | research and measurement line | source fitting plus several guarded prototypes; `modelsrc` remains default-off and the response/temporal paths require explicit test environment variables |

Do not merge the research branch wholesale. Relative to the merged 9.31 base it
adds about 4,700 lines and removes about 2,000 in `NVEncCore`, and contains debug
controls, rejected arms and experiment-only environment hooks alongside the
viable work. Promote a minimal component only after its independent gate passes.

## The architecture, layer by layer

1. **Admission and block selection.** Decide which blocks contain usable
   stochastic texture. This is not the same question as whether a model can fit
   that texture. Coverage, solver validity and semantic/stochastic evidence are
   separate states.
2. **Separation.** Bilateral denoising makes the clean base and residual.
   Production uses it because it is stable across ordinary and grain-bearing
   material. Motion separation can save substantially more bytes but remains a
   different base operator with disocclusion risk.
3. **Texture model.** Production fits AV1 AR coefficients from the denoiser
   residual. The residual is already whitened, which makes production grain too
   fine and can give lag-2 the wrong sign. `modelsrc=on` fits the AR texture from
   plane-detrended source blocks instead. This is the central architectural
   change and improves fine and coarse real-film texture by roughly an order of
   magnitude on the measured corpus.
4. **Strength and leak accounting.** Source fitting measures total source
   texture, while the encoded base retains some of it. Dense variance,
   realised-template normalization and post-encode leak work try to signal only
   the missing component. Whole-title amplitude is close; per-luma and chroma
   tails are not closed.
5. **Quantization and emission.** AV1 reduces the result to a compact, quantized
   scaling curve and AR table. Exact decoder replay has validated normative
   synthesis, but very coarse texture can still exceed what this representation
   reproduces exactly.
6. **Verification.** Energy, texture and base fidelity are deliberately
   separate measurements:

   - shared-source-mask `flat_retention.py` / `grain-watch.py` asks how much
     high-frequency energy survived;
   - lagged ACF and normalized spectra ask whether the texture is fine/coarse
     and spatially shaped correctly;
   - grain-disabled base comparison asks whether real picture detail was
     replaced by synthesized texture;
   - complete `libdav1d` decoding asks whether the stream is sound.

No one score answers all four questions. Finished-frame VMAF, SSIMULACRA2 and
Butteraugli penalize positionally different synthesized grain; use them on
grain-disabled, aligned bases for base fidelity, not to rank grain models.

## Findings that still hold

- The production analyzer is fast enough. The measured analyzer-kernel penalty
  was removed by the r4033/r4069 work; speed is not the quality blocker.
- Bilateral remains the conservative separator. Source fitting works with the
  same bilateral base, changes bytes by well under one percent in the isolated
  comparisons, and substantially improves delivered texture and amplitude.
- Source fitting is a better **model** on every measured positive and negative.
  Therefore model improvement cannot be used as admission evidence.
- Solver/coverage fallback is useful and implemented behind `modelsrc=on`.
  Rejected or insufficient source fits can fall back to the residual model.
- Covariance/texture-leak closure moves synthesized texture away from codec
  artifact and toward retained-original grain on the tested recompression
  pairs. It remains a guarded research path, not a production default.
- Production retention is centred near the target, not uniformly wrong. The
  established shared-mask population was median 0.971, with real lower and
  upper tails (p10 0.806, p90 1.318). A global gain correction would damage the
  centre while hiding the mechanism in the tails.

## Claims that must not drive another change

- The fitted `delivered ~= source^0.726` response came largely from a flawed
  investigation selector. Do not build a calibration from it.
- `emitted_vs_delivered.py` did not pass its consistency check. It cannot split
  analyzer intent from synthesis delivery.
- The 2.5x animation result used already-transcoded AV1 as its source and is
  retracted by `FINDINGS-2026-08-07-LIBRARY-AUDIT.md`.
- The fixed correlation/anisotropy conjunction detects properties of
  recompression and texture, but has not identified a case where FGS is proven
  worse than plain. It is not a release router.
- PSD shaping was a net loss on real film. Motion compression results do not
  authorize changing the separator while this sequence is quality-first.

## What remains open

1. **The real production tails.** The sound library estimator says some titles
   over-deliver and some under-deliver. Which scenes and content properties
   create those tails is not established.
2. **Source-fit safety on those tails.** The small film corpus sits near the
   centre of the production distribution. It cannot show whether source fitting
   closes or amplifies an outlier.
3. **Admission.** No quality-labelled harmful admission has survived a plain
   control. A universal source model may be viable, but that is unproven.
4. **Per-luma and chroma amplitude.** Aggregate luma is close while thin luma
   bands and chroma V can miss in either direction. Previous scalar/bin
   normalizers did not generalize.
5. **Coarse-model representability.** A correct source observation can still be
   approximated imperfectly by AV1's compact quantized AR model.

## Next gate: tail-first, same originals, four arms

Do not tune a threshold first. Freeze a population from the established
shared-source-mask verifier, then select:

- several repeatable upper-tail titles;
- several lower-tail titles;
- centre controls near 1.0;
- retained originals only, with duration, geometry, frame cadence and source
  provenance checked before encoding.

At three or more fixed scenes per title, decompose each encode by decoding the
same bitstream with synthesis on and off. Measure on one source-derived mask and
retain the per-scene values rather than only a title mean. Compare four arms at
the same rate and bilateral separator:

1. production residual fit;
2. bilateral `modelsrc=on` without response closure;
3. bilateral `modelsrc=on` with the guarded covariance/texture response;
4. plain AV1 without film-grain synthesis.

For every arm record luma-band energy, spatial ACF, grain-disabled base
fidelity, bytes, frame count and a complete dav1d decode. Chroma is recorded,
but no chroma correction is added in this experiment.

Decision boundary:

- If an apparent tail does not repeat across scenes with verified pairing, fix
  the monitor or sampling; do not touch the encoder.
- If production repeats the tail and source fitting moves both energy and
  texture toward the original without base damage, source fitting becomes a
  minimal promotion candidate.
- If source fitting worsens the tail but the guarded response closes it, the
  response mechanism—not a global gain—is the candidate.
- If all FGS arms are worse than plain on a verified title, that is the first
  quality-labelled harmful admission and becomes the admission-gate specimen.
- If the source model is accurate but all synthesized arms share the same
  texture miss, treat it as an AV1 representation limit rather than further
  analyzer tuning.

Only after this gate should per-luma or chroma-specific closure resume. It
directly tests the part of the real distribution that the existing six-film
corpus missed, and it can either promote the architectural change or produce
the negative specimen needed to make admission measurable.
